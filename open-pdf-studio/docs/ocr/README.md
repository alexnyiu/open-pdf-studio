# OCR release documentation

This directory defines the public capability boundary for Open PDF Studio OCR
and scanned-text editing on macOS.

- [macOS OCR and scanned-text release scope](MACOS_OCR_RELEASE_SCOPE.md)
- [macOS release-hardening evidence](MACOS_RELEASE_HARDENING.md)
- [Open PDF Studio 1.85.0 release notes](RELEASE_NOTES_1.85.0.md)
- [OCR third-party and fixture notices](THIRD_PARTY_NOTICES.md)

The scope document is authoritative when shorter product copy is ambiguous.
Recognition support, searchable-PDF persistence, and visible scanned-text
editing are separate capabilities and must not be presented as interchangeable.
